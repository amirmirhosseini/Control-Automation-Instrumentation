# Industrial Instrumentation - Spring 2026

This repository contains the assignments, analytical reports, and simulation projects for the **Industrial Instrumentation** course at the **University of Tehran**. 

The course covers the engineering of modern measurement loops, sensory performance analysis, analog signal conditioning architectures, and embedded system integration for industrial processes.

---

## Repository Curriculum Roadmap

* **HW 1: Sensor Characteristics & Data Modeling** | Static calibration analysis (hysteresis, dead zones, repeatability) and algorithmic plant identification utilizing Batch and Recursive Least Squares (RLS) estimation in **MATLAB**.
* **HW 2: Analog Signal Conditioning & Conditioning Chains** | Structural design of active multi-stage filters (band-pass, notch), wheatstone bridge conditioning for strain metrics, and precision amplification simulated via **Proteus** and **MATLAB/Simulink**.
* **HW 3: Embedded Control & Industrial Sensor Fusion** | Implementing bare-metal firmware in **STM32CubeIDE** for state-machine operations, PWM-driven motor logic, and multi-sensor automated voltage window sorting, co-simulated on **Proteus**.
