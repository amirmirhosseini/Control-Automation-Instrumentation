# Linear Control Systems - Homework 5

This repository contains the analytical validations, MATLAB simulations, and frequency domain analysis for **Homework 5** of the Linear Control Systems course at the **University of Tehran**.

## Course Concept Overview
The primary focus of this assignment is **Frequency Domain Analysis** and its application to system evaluation, stability assessment, and identification. The core concepts covered include:

* **Bode & Nyquist Representations:** Plotting and analyzing Bode diagrams and Nyquist plots to determine system behavior, gain/phase margins, and closed-loop stability limits.
* **Time-Delay Systems:** Evaluation of systems with transport lag using frequency criteria and Padé approximations.
* **System Identification:** Extracting the empirical transfer function of an unknown black-box system ($sys\_b.p$) based on its steady-state response to sinusoidal excitations across a spectrum of frequencies.
