# Linear Control Systems - University of Tehran (Winter-1404)

This repository contains the assignments, analytical derivations, and MATLAB simulations for the **Linear Control Systems** course at the **University of Tehran**.

---

## Repository Roadmap

* **HW 1 & 2: System Modeling** | Block diagrams, signal flow graphs, and transfer function extractions.
* **HW 3: Time-Domain Analysis** | Transient response, steady-state errors, and Routh-Hurwitz stability.
* **HW 4: Root Locus Techniques** | Analyzing parameter variations and basic closed-loop pole placement.
* **HW 5: Frequency Domain Analysis** | Bode/Nyquist plots, stability margins, and empirical system identification.
* **HW 6: Compensator Design & Linearization** | Designing Lead/Lag networks and state-space linearization of non-linear mechanical systems.
